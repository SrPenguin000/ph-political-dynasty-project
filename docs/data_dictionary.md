# Data Dictionary

This dictionary defines the final schema for the analytical Data Warehouse (Gold Layer) hosted in PostgreSQL, populated directly from the curated Parquet partitions and staging files generated by the Airflow pipeline.

## 1. `dim_person`

**Source:** `data/staging/politicians.parquet`

Core dimension table containing longitudinal identities of all politicians.

| Field Name | PostgreSQL Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `person_uid` | `VARCHAR(50)` | FALSE | **Primary Key.** Unique identifier cross-referencing HF, OpenHalalan, Ateneo, and Roster records. |
| `first_name` | `VARCHAR(100)` | TRUE | Standardized first name. |
| `last_name` | `VARCHAR(100)` | TRUE | Standardized surname used for base kinship linking. |
| `middle_initial` | `VARCHAR(10)` | TRUE | Inferred or provided middle initial. |
| `suffix` | `VARCHAR(10)` | TRUE | Generational suffix (e.g., Jr., Sr., III) separated from names. |
| `display_name` | `VARCHAR(255)` | FALSE | Standardized full name for dashboard UI rendering. |
| `home_province` | `VARCHAR(100)` | TRUE | Most frequently contested province. |
| `clan_id` | `VARCHAR(50)` | TRUE | **Foreign Key** to `dim_clan`. Null if the politician has no strong/medium relatives in the network. |

## 2. `fact_electoral_membership`

**Source:** `data/curated/official_terms_dynastic/`

Partitioned transactional fact table of election winners per cycle.

| Field Name | PostgreSQL Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `person_uid` | `VARCHAR(50)` | FALSE | **Foreign Key** linking to `dim_person`. |
| `year` | `INT` | FALSE | Election year (1988–2025). |
| `position` | `VARCHAR(100)` | FALSE | Standardized office title (e.g., MAYOR, COUNCILOR, GOVERNOR). |
| `province_std` | `VARCHAR(100)` | FALSE | Standardized province name. |
| `town_std` | `VARCHAR(100)` | TRUE | Standardized municipality/city. Null for provincial and district-level positions. |
| `party` | `VARCHAR(100)` | TRUE | Reported political party alignment. |
| `is_dynastic` | `BOOLEAN` | FALSE | TRUE if the official has a known relative who held office in this year or prior. |
| `is_fat_dynasty` | `BOOLEAN` | FALSE | TRUE if a relative holds office in the same province in the same year (Ateneo benchmark). |

## 3. `dim_clan`

**Source:** `data/staging/clans.parquet`

Dimension table defining inferred paternal family networks.

| Field Name | PostgreSQL Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `clan_id` | `VARCHAR(50)` | FALSE | **Primary Key.** Auto-generated sequence ID (e.g., `CLAN-00001`). |
| `clan_label` | `VARCHAR(150)` | FALSE | Dashboard display label (e.g., "AMPATUAN \| MAGUINDANAO"). |
| `n_members` | `INT` | FALSE | Total distinct politicians belonging to the clan network. |
| `first_year` | `INT` | FALSE | First year any clan member held elected office. |

## 4. `fact_town_stronghold`

**Source:** `data/curated/town_dynasty_stronghold/`

Aggregated metrics used to render Streamlit geographic maps.

| Field Name | PostgreSQL Type | Nullable | Description |
| :--- | :--- | :--- | :--- |
| `year` | `INT` | FALSE | Election year (1988–2025). |
| `province_std` | `VARCHAR(100)` | FALSE | Standardized province name. |
| `town_std` | `VARCHAR(100)` | FALSE | Standardized municipality/city name. |
| `n_officials` | `INT` | FALSE | Total local officials tracked in the town-year. |
| `dynastic_share` | `FLOAT` | FALSE | Percentage of officials flagged as `is_dynastic`. |
| `mayor_dynastic` | `BOOLEAN` | TRUE | TRUE if the town's elected Mayor is dynastic. |
| `top_clan_share` | `FLOAT` | FALSE | Share of total seats held by the most dominant family. |
| `stronghold_level` | `VARCHAR(50)` | FALSE | Categorical classification (Low, Moderate, High, Stronghold). |
